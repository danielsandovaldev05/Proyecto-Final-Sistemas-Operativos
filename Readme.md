# Simulador de Planificador de Procesos (CPU Scheduler)
 
Proyecto final de Sistemas Operativos. Python 3.9+ y solo librería estándar (tkinter).

En esta primer versión se diseño un archivo .py (de Python) para diseñar los diferentes algoritmos de planificación como el FCFS, el SJF, Round Robin, entre otros, para después utuilizarlos con la interfaz de usuarioy ver si funcionan.
